# Нативна C-версія ZakonDownloader

Це окрема нативна Windows-версія програми. Початкову Python-версію не видалено: обидві можна використовувати паралельно, вони сумісні з основними користувацькими даними.

## Збірка і запуск

У PowerShell з кореня проєкту:

```powershell
.\scripts\build_native_c.ps1
.\native_c\dist\ZakonDownloader.exe
```

Сценарій збірки запускає тести локалізації, парсера, сумісності налаштувань та історії, локального перегляду TXT і PDF-друку, а потім створює оптимізований 64-бітний GUI-файл без консолі. Для збирання потрібен Zig із компілятором `zig cc`; перевірена версія — 0.17.0. Скрипт шукає Zig у `PATH` або в `.work\tools\zig-0.17.0`. Якщо компілятор розташований в іншій папці:

```powershell
.\scripts\build_native_c.ps1 -ZigPath 'C:\Tools\zig\zig.exe'
```

Параметр `-SkipTests` пропускає тести, але для звичайної збірки рекомендовано залишити їх увімкненими. Готовий застосунок: `native_c\dist\ZakonDownloader.exe`.

## Робота з локальними законами

У розділі **«Мої документи»** відображаються вже збережені `.txt`-файли. Виберіть документ і натисніть **«Читати в програмі»**, щоб відкрити його у вбудованому переглядачі. Переглядач підтримує пошук наступного збігу, перемикання між чистим текстом закону та повним файлом із метаданими, відкриття вихідного документа у браузері та запуск пов’язаного `.txt`-файлу.

Кнопка **«Експортувати PDF»** створює поряд із текстовим документом окремий PDF у книжковому стилі: з титульною сторінкою, назвою й метаданими, виразними заголовками, читабельним текстом і нумерацією сторінок. Вихідний `.txt` не змінюється. Для PDF потрібен системний принтер **Microsoft Print to PDF** (або його треба ввімкнути в компонентах Windows). Після експорту файл можна відкрити кнопкою **«Відкрити PDF»**.

Кнопка переходу до джерела відкриває лише перевірене HTTPS-посилання на `zakon.rada.gov.ua`; для файла без валідного джерела ця дія недоступна. Переглядач працює з локально збереженим текстом і не завантажує закон повторно.

## Можливості та безпека

C-версія містить огляд, фонове завантаження документів, локальну бібліотеку, історію з пошуком і фільтрами, світлу й темну теми, режими «Користувач» / «Розробник», параметри та журнали. Режим користувача залишає основні щоденні дії, а режим розробника додає технічні журнали й мережеві параметри. Це перемикач видимості, а не межа доступу чи безпеки.

Завантажувач приймає HTTPS-посилання на документи з `zakon.rada.gov.ua` у форматі `/laws/show/<id>`. HTTP-шар має обмеження розміру відповіді, повторні спроби для тимчасових помилок і перевірку переходів лише на той самий HTTPS-хост. CAPTCHA, авторизація й інші обмеження доступу не обходяться.

## Спільні дані

Обидві версії використовують ті самі налаштування, папку документів та SQLite-історію:

- Налаштування: `%USERPROFILE%\ZakonDownloader\config\settings.json`
- Документи: `%USERPROFILE%\ZakonDownloader\data\documents` (якщо шлях не змінено в налаштуваннях)
- Історія: `%USERPROFILE%\ZakonDownloader\data\history\history.db`
- Журнал C-версії: `%USERPROFILE%\ZakonDownloader\data\logs\native_c.log`

SQLite завантажується з системної `winsqlite3.dll`; окрему SQLite-бібліотеку чи Python до `.exe` не включено. Додатковий індекс історії не видаляє й не переписує наявні записи. Короткий таймаут очікування SQLite полегшує доступ, коли обидві версії відкриті одночасно.

## Перевірки й обмеження

Перевірено C-тести парсера на зразку сторінки Ради, дозволені та відхилені URL, метадані, імена файлів, HTML-сутності й межі вкладеності; інтеграційні тести міграції налаштувань і сумісності схеми історії; читання UTF-8 локальних документів; експорт через Microsoft Print to PDF; а також GUI-сценарій відкриття локального документа, режимів тексту, експорту PDF і перемикання режимів інтерфейсу. Окремо Python-версія проходить повний набір регресійних тестів.

Під час перевірки збірки живе завантаження із сайту не виконувалося: для нього потрібен інтернет-доступ до сайту Верховної Ради. Парсер призначений саме для структури сторінок цього сайту, не для довільних вебсайтів. Підтримувана ціль — 64-бітна Windows 10/11 із доступною `winsqlite3.dll`.


## Додані функції у 1.2.0-C

У вбудованому переглядачі:

- **Зміст:** автоматичний список рядків, що починаються з «Розділ», «Стаття», «Глава», «Підрозділ», «Частина», «Прикінцеві положення» або «Перехідні положення». Вибір заголовка переходить до нього в чистому або повному тексті; список обмежений 1000 пунктами.
- **Закладки й відновлення:** кнопка **«Закладка +»** зберігає поточний рядок із короткою міткою; список дозволяє переходити до закладки або видаляти її. Позиція читання зберігається лише після зміни позиції — періодично, при переході на іншу сторінку інтерфейсу і при закритті програми. Прогрес і закладки лежать у таблицях `reader_progress` та `reader_bookmarks` спільної бази `history.db`; записи таблиці `history` не видаляються й не мігрують.
- **Масштаб:** **A− / A+** змінюють розмір Georgia від 14 до 30 px з кроком 2 px; обмеження не дає випадково отримати надмірно великий шрифт.
- **Цитата:** виділіть у Reader до 20 000 символів та натисніть **«Копіювати цитату»**. До цитати додаються назва документа й URL джерела; якщо URL у файлі відсутній, додається локальний шлях.

У розділі **«Історія»** кнопка **«Експорт CSV»** створює файл з усіма записами, а не лише відфільтрованими. Експорт не блокує вікно, записується атомарно у `%USERPROFILE%\ZakonDownloader\data\exported_logs\`, має UTF-8 BOM, коректно екранує коми, лапки й переноси рядка та нейтралізує початкові символи формул у полях. Лімітується 256 МБ на один експорт; попередні файли не перезаписуються.

Фільтрація локальної бібліотеки більше не перечитує каталог на кожну зміну пошукового поля: перелік оновлюється при відкритті сторінки або явному натисканні **«Оновити список»**, а пошуковий фільтр лише перемальовує вже завантажені записи. Перемальовування таблиці тимчасово вимикається для зменшення мерехтіння. Скрипт збірки запускає окремі перевірки SQLite-прогресу/закладок і CSV та після успішної збірки прибирає непотрібний для запуску PDB-символ із `native_c\dist`.


## Мова інтерфейсу та візуальне оформлення (1.3.0-C)

Відкрийте **Налаштування → Мова інтерфейсу**, щоб одразу перемкнути C-інтерфейс на українську, англійську, німецьку, французьку, іспанську, португальську або спрощену китайську. Вибір зберігається в `settings.json`; наявні конфігурації без поля `language` безпечно відкриваються українською. Тексти законів залишаються мовою джерела. Python-версія поки має український інтерфейс, але при збереженні налаштувань не скидає мову C-версії.

Багаторозмірні значки й знак бренду вбудовані в `.exe`; для редагування lockup використовуйте `assets/ZakonDownloader-brand-lockup.svg` та `assets/ZakonDownloader-logo-mark.png`. Кольори світлої й темної тем залишені оригінальними; інтерфейс отримав масштабовану типографіку й легкі тіні карток.

Файл `locales/ui-translations.json` є джерелом текстів. `scripts/generate_i18n.py` перевіряє набори перекладів, placeholders і переноси рядків та відтворює `src/i18n.c`. Генерація не потрібна для запуску готового `.exe`: усі рядки вже вбудовано у програму.

Збірка перевіряє локалізацію окремими C-тестами та створює ресурсні іконки. За замовчуванням сценарій не перезапише саме той файл, процес якого запущений. Для компіляції у відокремлений файл, не закриваючи відкриту програму, використовуйте:

```powershell
.\scripts\build_native_c.ps1 -OutputPath .work\candidate\ZakonDownloader.exe
```

Після зміни коду запустіть новий `.exe` — вже відкрите вікно не може самостійно підмінити завантажену версію.
