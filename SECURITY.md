# Повідомлення про вразливість

Не публікуйте вразливість, робочий exploit, персональні дані, API-ключі чи токени у відкритих Issues або Pull Requests.

Після створення GitHub-репозиторію повідомляйте про чутливі проблеми через **Private vulnerability reporting / Security Advisories**, якщо цю функцію буде ввімкнено. Якщо вона недоступна, спершу зверніться до власника репозиторію приватним каналом і погодьте безпечний спосіб передачі деталей.

Проєкт не має окремої команди безпеки або гарантованого SLA реагування. Не надсилайте реальні облікові дані чи секрети для відтворення проблеми.
