# Внесок у ZakonDownloader

## Перед змінами

1. Створіть окрему гілку від `main` і робіть невеликі тематичні зміни.
2. Не додавайте користувацькі налаштування, завантажені закони, журнали, бази SQLite, архіви релізів або файли з ключами/токенами. Локальні й генеровані артефакти відфільтровані через `.gitignore`.
3. Для Python-змін дотримуйтеся наявної структури `src/zakon_downloader/` і додавайте регресійні тести в `tests/`.
4. Для C-змін зберігайте сумісність формату налаштувань, історії SQLite та обмежень доступу до `zakon.rada.gov.ua`.

## Перевірки

Python-тести з кореня проєкту:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
```

Нативна C-збірка й повний набір її тестів у Windows потребують Zig; перевірена версія — 0.17.0:

```powershell
.\scripts\build_native_c.ps1 -ZigPath 'C:\Tools\zig\zig.exe'
```

Якщо EXE уже відкритий, збирайте в інший шлях через `-OutputPath .work\candidate\ZakonDownloader.exe`, не закриваючи програму.
