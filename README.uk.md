# ZakonDownloader

[English](README.md) | [Українська](README.uk.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português](README.pt.md) | [简体中文](README.zh-CN.md)

ZakonDownloader — це безкоштовний застосунок із відкритим вихідним кодом для Windows, призначений для завантаження загальнодоступних нормативно-правових документів з офіційного вебсайту Верховної Ради України — [`zakon.rada.gov.ua`](https://zakon.rada.gov.ua/). Він містить застосунок на Python/PySide6 і нативний застосунок на C/Win32. Обидві версії використовують однакові налаштування, папку документів і журнал історії SQLite.

> **Область застосування та безпека:** застосунок працює з публічними документами на `zakon.rada.gov.ua`. Він не обходить CAPTCHA, вхід до облікового запису, засоби захисту від ботів або обмеження доступу. Не вводьте паролі, ключі API чи токени.

## Можливості

- Завантаження документа за прямим HTTPS-посиланням у фоновому режимі.
- Збереження результату як файлу `.txt` у кодуванні UTF-8 і ведення локальної історії в SQLite.
- Перегляд локальної бібліотеки документів і пошук або фільтрування історії завантажень.
- Використання світлого або темного оформлення та перемикання між режимами інтерфейсу «Користувач» і «Розробник».
- У нативному застосунку на C — читання збережених документів у вбудованому переглядачі, навігація виявленим змістом, пошук у тексті, збереження закладок і продовження читання, зміна розміру тексту, копіювання цитати з даними про джерело та експорт PDF у форматі книжки.
- У нативному застосунку на C — експорт історії до CSV. Експорт використовує UTF-8 із BOM і захищений від інтерпретації як формул у табличних редакторах.

Завантажувач приймає загальнодоступні URL документів на `zakon.rada.gov.ua` у форматі `/laws/show/<id>`. Він перевіряє перенаправлення HTTPS на той самий хост, обмежує розмір відповіді та повторює спроби після тимчасових помилок; це не універсальний засіб для скрапінгу вебсайтів. Завантажені тексти нормативно-правових документів залишаються мовою оригіналу — мова інтерфейсу не перекладає документи.

## Вимоги

- Windows 10 або Windows 11, 64-розрядна версія.
- Доступ до Інтернету для отримання документів.
- Python 3.11 або новішої версії та Python Launcher (`py`) для запуску версії на Python.
- Zig 0.17.0 із `zig cc` для збирання нативної версії на C.

## Запуск версії на Python

У PowerShell клонуйте репозиторій і виконайте наведені нижче команди з його кореневої папки:

```powershell
git clone https://github.com/Danuha99/ZakonRadaParser.git
Set-Location ZakonRadaParser
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m zakon_downloader
```

Активувати віртуальне середовище не потрібно; викликайте виконуваний файл Python, як показано вище. Замініть селектор версії Python, якщо потрібна певна встановлена версія, наприклад `py -3.11`.

### Збирання автономного виконуваного файлу Python

Установіть залежності для розробки, а потім запустіть сценарій пакування з PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\scripts\build_exe.ps1
```

Виконуваний файл буде записано до `dist\ZakonDownloader.exe`.

## Збирання нативної версії C/Win32

У кореневій папці репозиторію в PowerShell:

```powershell
.\scripts\build_native_c.ps1
.\native_c\dist\ZakonDownloader.exe
```

Для збирання потрібен Zig 0.17.0 (`zig cc`) у `PATH`. Якщо Zig установлено в іншому місці, укажіть його шлях:

```powershell
.\scripts\build_native_c.ps1 -ZigPath 'C:\Tools\zig\zig.exe'
```

Перед створенням 64-розрядного виконуваного файлу з графічним інтерфейсом сценарій збирання запускає перевірки нативного аналізатора, локалізації, налаштувань та історії, а також пов’язані перевірки. Результат зберігається в `native_c\dist\ZakonDownloader.exe`.

## Локальний переглядач та експорт

У нативному застосунку на C відкрийте **Мої документи**, виберіть збережений файл `.txt` і натисніть **Читати в застосунку**. Переглядач може показувати очищений юридичний текст або повний збережений файл, знаходити текст, переходити між виявленими розділами, зберігати закладки та позицію читання, а також копіювати цитату з її назвою й URL джерела. **Експортувати PDF** створює окремий PDF у форматі книжки поруч із текстовим файлом; для цього потрібен принтер Windows **Microsoft Print to PDF**, а початковий файл `.txt` не змінюється.

Експорт історії до CSV записується до `%USERPROFILE%\ZakonDownloader\data\exported_logs\`. Ці операції експорту не видаляють наявні документи та записи історії.

## Розташування даних

За замовчуванням обидва застосунки використовують такі розташування:

| Дані | Шлях за замовчуванням |
|---|---|
| Налаштування | `%USERPROFILE%\ZakonDownloader\config\settings.json` |
| Документи | `%USERPROFILE%\ZakonDownloader\data\documents` |
| Історія SQLite | `%USERPROFILE%\ZakonDownloader\data\history\history.db` |
| Журнал нативного C | `%USERPROFILE%\ZakonDownloader\data\logs\native_c.log` |

Папку документів можна змінити в налаштуваннях застосунку. Якщо потрібно зберегти завантажені файли, налаштування, закладки чи історію, створіть резервну копію папки даних `ZakonDownloader` перед її переміщенням або видаленням.

## Тести

Установіть залежності для розробки та запустіть набір тестів Python із кореневої папки репозиторію:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
```

Також можна запустити `scripts\run_tests.ps1` у PowerShell. Сценарій збирання нативної версії C за замовчуванням запускає власні тести; параметр `-SkipTests` доступний, але для звичайних збирань його використання не рекомендується.

## Структура репозиторію

- `src/zakon_downloader/` — застосунок на Python.
- `native_c/` — нативний застосунок на C/Win32, переклади, ресурси та тести.
- `tests/` — тести Python.
- `scripts/` — сценарії збирання, тестування та створення локалізації.
